This is the Expo SDK 57 application root that wires together build, runtime, and deployment configuration. `package.json` declares `expo-router/entry` as the main module and pins all SDK 57 dependencies (camera, location, secure-store, sqlite, task-manager, vision-camera, fast-tflite, supabase-js, drizzle-orm, zustand, tanstack-query, i18next, nativewind). `app.json` defines the Expo manifest: bundle ID `com.dermsight.app`, portrait orientation, deep-link scheme `dermsight`, splash screen, Android adaptive icons using the medical teal palette (`#0D9E94`), declared native permissions (camera, fine/coarse location, storage), and config plugins for `expo-router`, `expo-splash-screen`, `expo-location`, and `expo-camera`. The build pipeline chains `metro.config.js` → `babel.config.js` (using `babel-preset-expo` with `jsxImportSource: nativewind`) → `tailwind.config.js` (medical-themed color tokens) → `global.css` (NativeWind entry). TypeScript path aliases `@/*` → `./src/*` are configured in `tsconfig.json`. `ARCHITECTURE.md` documents the layered design: UI screens under `app/` consume Zustand stores and feature hooks from `src/features/`, which read/write local SQLite via Drizzle ORM (`src/db/`), trigger an out-of-process sync engine to Supabase, and run on-device TFLite inference over a quantized H-CBM model bundled under `src/ml/assets/`. Assets include locale bundles (`assets/locales/{en,fr,sw}.json`), platform-specific iconography (`assets/icons`, `assets/images`, `assets/splash`, `assets/expo.icon`), and a `scripts/reset-project.js` helper scaffolds a blank `src/app` layout.
