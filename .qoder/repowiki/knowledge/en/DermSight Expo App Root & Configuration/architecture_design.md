This is the top-level project manifest and configuration layer for an Expo SDK 57 React Native app built with `expo-router/entry` as the main module. `app.json` declares the Expo manifest (bundle ID `com.dermsight.app`, deep-link scheme `dermsight`, portrait orientation, splash screen) and configures native capabilities via plugins (`expo-splash-screen`, `expo-location`, `expo-camera`) and Android permissions (camera, location, storage). The build pipeline chains `metro.config.js` → `babel.config.js` (using `babel-preset-expo` with `jsxImportSource: nativewind`) → `tailwind.config.js` (medical teal `#0D9E94` theme tokens) → `global.css` (NativeWind entry), with TypeScript path aliases `@/*` → `./src/*` in `tsconfig.json`. Assets under `assets/` include locale bundles (`en.json`, `fr.json`, `sw.json`), platform icons (`android-icon-*`, `expo.icon`), per-screen iconography, and the logo. `ARCHITECTURE.md` documents the layered design: UI screens in `app/` consume Zustand stores and feature hooks from `src/features/`, which read/write local SQLite via Drizzle ORM (`src/db/`), trigger an out-of-process sync engine to Supabase, and run on-device TFLite inference over a quantized H-CBM model bundled under `src/ml/assets/`. `package.json` pins all SDK 57 dependencies and exposes scripts for `start`, `android`, `ios`, `web`, `tunnel`, `lint`, and a `reset-project` helper that scaffolds a blank `src/app` layout.
