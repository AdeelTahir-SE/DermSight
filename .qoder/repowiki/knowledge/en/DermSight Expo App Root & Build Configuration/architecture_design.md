This is an Expo SDK 57 project whose entry point is `expo-router/entry` declared in `package.json`, with file-based routes under `app/` grouped into `(auth)` and `(app)` route groups. The build pipeline chains `metro.config.js` (wrapping Expo's default Metro config via `withNativeWind`) → `babel.config.js` (using `babel-preset-expo` with `jsxImportSource: nativewind`) → `tailwind.config.js` defining a medical-themed color palette (primary teal `#0D9E94`, navy, risk-tier colors). TypeScript uses path aliases `@/*` → `./src/*` and `@/assets/*`. Platform configuration lives in `app.json`, declaring bundle ID `com.dermsight.app`, portrait orientation, deep-link scheme `dermsight`, and native permissions for camera, fine/coarse location, and storage; plugins register `expo-router`, `expo-splash-screen`, `expo-location`, and `expo-camera`. Assets include localized i18n JSON files (`en.json`, `fr.json`, `sw.json`) under `assets/locales/`, tab icons, and Android adaptive icon assets. Per `ARCHITECTURE.md`, the runtime codebase follows a layered design: UI screens in `app/` consume Zustand stores and feature hooks from `src/features/`, which read/write local SQLite via Drizzle ORM (`src/db/`), trigger an outbox-pattern sync engine to Supabase, and run on-device TFLite inference (`react-native-fast-tflite`) over a quantized H-CBM model bundled under `src/ml/assets/`.
