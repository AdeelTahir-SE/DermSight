This leaf module is the project root that declares the Expo application manifest, bundler pipeline, and static assets consumed by the rest of the codebase. `app.json` defines the Expo config (bundle ID `com.dermsight.app`, deep-link scheme `dermsight`, portrait orientation, splash screen) and registers native plugins (`expo-splash-screen`, `expo-location`, `expo-camera`) with platform-specific permission strings under `android.permissions`. The build chain is: Metro (`metro.config.js`) wraps the default Expo config with `withNativeWind` pointing at `global.css`; Babel (`babel.config.js`) uses `babel-preset-expo` with `jsxImportSource: nativewind`; Tailwind (`tailwind.config.js`) extends theme tokens (medical teal `#0D9E94`, navy, risk-tier colors) scoped to `src/**/*.{js,jsx,ts,tsx}`; TypeScript (`tsconfig.json`) extends `expo/tsconfig.base` with strict mode and path aliases `@/*` → `./src/*` and `@/assets/*` → `./assets/*`. Runtime dependencies are pinned in `package.json` (Expo SDK 57, React 19, expo-router, Drizzle ORM, Supabase client, Zustand, TanStack Query, i18next, react-hook-form + zod). Assets under `assets/` include locale bundles (`en.json`, `fr.json`, `sw.json`), per-screen iconography, Android adaptive icons, and the ML model checkpoint (`models/best_cbm_full.pth`). Scripts expose `start`, `android`, `ios`, `web`, `tunnel`, `lint`, and a `reset-project` helper.
