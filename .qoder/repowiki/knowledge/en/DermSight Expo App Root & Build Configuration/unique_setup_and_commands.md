Run `npx expo start` or `npm run android` / `npm run ios` / `npm run web` to launch; use `npm run reset-project` to scaffold a blank `src/app` layout. Requires an `.env` file with `SUPABASE_URL` and `SUPABASE_ANON_KEY` (see `.env.example`). Must be built with `expo-dev-client` (not Expo Go) because it uses native modules. The TFLite model is produced offline via `ai-edge-torch` from a PyTorch checkpoint and then bundled into `src/ml/assets/` — this conversion step is separate from the RN build.
